# How to run
  > ## Mac
  > ```bash
  > python3 -m venv .venv
  > source ./.venv/bin/activate
  > pip install -r ./requirements.txt
  > python -m app.run
  > ```
  > ## Windows
  > ```
  > python -m venv .venv
  > .\.venv\scripts\Activate
  > pip install -r ./requirements.txt
  > python -m app.run
  > ```
